# BachavSetu

BachavSetu is a disaster relief platform that makes emergency management faster and more efficient for affected communities and responders.

---

## Key Features

- **Incident Reporting**: Report emergencies and disasters instantly with an easy-to-use form.
- **Supply Requests**: Request vital relief materials and track support status.
- **Resource Tracking**: Monitor resources and deployment in real time.
- **Assignment Management**: Authorities assign and manage field tasks for responders.

---

## How to Use

1. **Visit the Live Platform:**  
   [BachavSetu Frontend](https://bachav-setu.vercel.app)

2. **Register or Log in**:  
   Create an account or sign in as a responder or authority.

3. **Report an Incident**:  
   Submit details about a disaster event from the dashboard.

4. **Request Supplies**:  
   Fill out a supply request to get necessary resources.

5. **Stay Updated**:  
   View assignment status, resource deployments, and response actions—all in real time.
